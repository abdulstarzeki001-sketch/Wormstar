# Wormstar Custom Direction Pack

هذا المجلد يتيح للمستخدم تحديد **اتجاه خاص** لذكائه، بدلاً من تقييده بتخصص معيّن مسبقاً.

| الملف | الغرض |
|---|---|
| `system_prompt.md` | الهوية والرسالة والأسلوب |
| `rules.yaml` | توثيق قواعد العمل وترتيب الأولويات |
| `permissions.json` | مثال للقيم التي تحفظ في سياسة D1 |
| `workflow.md` | سير العمل |
| `knowledge.md` | قالب المعرفة |
| `training.jsonl` | أمثلة سؤال/إجابة مفضلة |
| `corrections.md` | تسجيل وتصحيح الأخطاء |
| `tests.json` | حالات اختبار السياسة |

## ما الذي يطبّقه التطبيق فعلياً؟

من استوديو Wormstar عدّل: **المهمة الأساسية، الأنماط المسموحة، الكلمات المطلوبة، حدود أحجام المدخلات والمخرجات، استخدام الذاكرة، استيراد الويب، الحذف، وأسلوب الإجابة**. يحفظ Cloudflare هذه السياسة داخل D1، ويطبق الحظر البرمجي على عمليات API المحددة. تغيير ملفات هذا المجلد على GitHub لا يحدث سياسة D1 آلياً.

الملفات `system_prompt.md` و`rules.yaml` و`workflow.md` توجيهية. لا يمكن للنموذج ضمان الالتزام الدلالي الكامل بتعليمات نصية مهما كانت؛ أضف اختبارات وموافقات للمهمات عالية المخاطر.

## البداية السريعة

1. افتح `wormstar-ai-lab` واختر **استوديو تخصيص الذكاء وذاكرته**.
2. ضع مهمة محددة وصِف ما يجب وما لا يجب فعله.
3. من **سياسة التشغيل** فعّل الأنماط المطلوبة فقط واضبط حدود الوظائف.
4. احفظ السياسة؛ ستُطبق على الطلبات اللاحقة في Worker.
5. ارفع ملفات المعرفة والتصحيحات إلى المكتبة، واستعمل Supabase لنسخة إضافية.
6. جرّب اختبارات `tests.json` وعدّل القواعد عند الحاجة.

**النطاق:** هذا الضبط لا يغير ملفات Python/Ollama الأصلية في جذر المستودع، ولا يضيف تنفيذ شيفرة عن بعد.

# STAR OSINT AI — v2.0

## تغييرات حقيقية في هذه النسخة

- لوحة «مركز التحليلات» تعرض أعداد الفحوص والأنواع والمشاريع والسجل التدقيقي من SQLite.
- جدول `scan_sources` جديد يُنشأ تلقائياً باستخدام `CREATE TABLE IF NOT EXISTS`، دون حذف الجداول القديمة.
- تظهر حالة ونتائج وأخطاء كل مصدر جمع في صفحة الفحص وواجهة الحالة JSON.
- مقارنة فحصين متتابعين لنفس المشروع من المصادر المشتركة **الناجحة** فقط، مع التنبيه لاحتمالية تغير مصدر البيانات.
- ملاحظات رصد SPF وDMARC وCAA من DNS بدون اعتبار عدم الرصد ثغرة مؤكدة.
- بصمة SHA-256 قابلة للتكرار للنتائج الفعلية (نوع/قيمة/مصدر)؛ البصمة ليست توقيعاً رقمياً.
- البحث والتصفية محلياً داخل جدول الأدلة؛ لا يرسل كلمات البحث لأي خدمة خارجية.
- تصدير تقارير HTML / Markdown / JSON محدثة بمعلومات المصدر والمقارنة والتجزئة؛ CSV يبقى للأدلة.
- النسخ الاحتياطي باستخدام SQLite online backup، مع تضمين .env عند توفره.
- تعرّض نسخة Ollama المحلية بيانات محددة بحد أقصى 160 دليلاً، أما التقارير فتتضمن جميع الأدلة المحفوظة.

## نطاق الحماية

- مصمم لوحدة تحكم محلية على `127.0.0.1:8787`، وليس لخادم عام متعدد المستخدمين.
- جمع OSINT من DNS وCT والسجلات العامة؛ بلا مسح منافذ أو استغلال أو محاولات دخول.
- لا يقبل عناوين IP أو النطاقات الخاصة كأهداف.
- بيانات DNS وCT قد تتغير أو تتأخر؛ المقارنة تشير إلى اختلاف نتائج الرصد وليست إثباتاً قاطعاً.
- الذكاء الاصطناعي اختياري؛ الاستنتاجات قد تخطئ ويجب مراجعتها.
- النسخ الاحتياطية تحتوي بيانات حساسة وربما كلمة مرور المدير المجزأة وسر الجلسة؛ لا ترفعها إلى أي مكان عام.

## تحديث مستخدم v1.1

1. أوقف الخدمة القديمة.
2. من داخل `~/Downloads/star-osint-ai` شغّل `.venv/bin/python scripts/backup.py` بعد إضافة ملفات v2، أو انسخ `.env` و`data` يدوياً قبل الاستبدال.
3. فك ضغط ZIP التحديث فوق `~/Downloads`، ولا تحذف مجلد المشروع.
4. شغّل `.venv/bin/python -m pytest -q` ثم `./start.sh`.

شاهد `QUICKSTART_V2_AR.txt` للأوامر المختصرة.

# استيراد ملفات OneDrive الأصلية إلى GitHub خاص

**الحالة:** لم تُرفع أصول OneDrive الحساسة إلى GitHub حتى الآن. أداة النقل جاهزة وتتحقق من خصوصية المستودع قبل رفع أي ملف.

## سبب عدم نشر الأصول في المستودع العام

تتضمن بعض صفحات HTML الأصلية رمز QR طويلًا ورقم هاتف ومعلومات تعريف أو اتصال. النسخ العامة الحالية منقحة. الصور الأصلية موجودة في OneDrive ولم يتم رفعها كـPNG إلى GitHub.

## تشغيل النقل الآمن على iSH أو Kali

1. نزّل المجلد الكامل من OneDrive بصيغة ZIP وفك ضغطه في مجلد محلي خاص.
2. على iSH: `apk add git github-cli unzip`. وعلى Kali: `sudo apt install git gh unzip`.
3. نفّذ `gh auth login` بحساب GitHub الخاص بك، ولا تشارك رمز المصادقة في أي محادثة.
4. من مجلد Star-Cyber-Audit-iSH نفّذ الأوامر:

```sh
git pull --ff-only origin main
sh tools/ish/upload_onedrive_archive_private.sh "/path/to/extracted/onedrive-folder"
```

الوجهة الافتراضية: `abdulstarzeki001-sketch/Star-Cyber-Audit-Private-Archive`.
السكربت ينشئ مستودعًا جديدًا بخيار Private إذا لم يكن موجودًا ويُعيد التحقق من خصوصيته قبل الدفع. لا يحاول الكتابة إلى المستودع العام.

## الحماية والحدود

- يحتفظ بالأسماء والمحتوى الأصليين، بما في ذلك الصور، داخل `archives/onedrive-uboor/` في المستودع الخاص.
- يرفض الملفات الرمزية ويحد من عدد الملفات (200) وأحجامها (90MB للملف).
- لا يتصل بخوادم حكومية ولا ينفذ JavaScript مؤرشفًا.
- يرفض الوجهة إذا كانت Public. لا يزيل معلومات من الملفات الأصلية لأنه مصمم للحفظ الخاص.
- المستودع الخاص لا يعني موافقة الجهة الأصلية على إعادة النشر، ولا يعني أن هذه اللقطات نسخة حكومية صالحة للتشغيل.

## التحقق

بعد النقل افتح رابط المستودع الخاص وتأكد من Private وظهور العناصر الثمانية بأحجامها. لا تشارك أسماء الملفات الحساسة أو رموز QR علنًا.

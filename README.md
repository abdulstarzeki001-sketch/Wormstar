# Wormstar

## التشغيل

شغّل Ollama أولًا، ثم شغّل المساعد من جذر المشروع:

```bash
ollama serve
python3 wormgpt.py
```

يتطلب تشغيل المساعد وجود نموذج Ollama باسم `llama3.2:1b`:

```bash
ollama pull llama3.2:1b
```

## الأدوات والتحقق

- يراجع المساعد النتيجة النهائية، ويمكنه إعادة المحاولة ضمن حد الجولات.
- يتوفر فحص مواقع للقراءة فقط عبر HTTPS على المنفذ 443؛ يتطلب موافقة المستخدم
  ويرفض عناوين IP الخاصة أو المحلية، ولا يتبع التحويلات.
- تظل الكتابة إلى الملفات وتشغيل Python أو أوامر النظام مشروطة بموافقة المستخدم.

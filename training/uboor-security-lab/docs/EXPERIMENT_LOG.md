# سجل مختبر UBOOR — تجارب محلية اصطناعية

كل التجارب أدناه **محاكاة أو فحص لملفات محلية**؛ لا تتصل بخادم UBOOR ولا تدل على ثغرات تشغيلية فيه.

| التجربة | الاختبار المحلي |
|---|---|
| HAR parsing | استخراج طرق HTTP ومسارات الطلبات من HAR اصطناعي |
| Quantity verification | اختبار تطابق الوزن والكميات مع دعم الأرقام والنص الرقمي |
| Duplicate detection | اكتشاف طلبين متطابقين في سجل تدريب اصطناعي |
| Authorization precedence | محاكاة تعارض ترويسة Authorization برموز وهمية |
| Race condition | توضيح Lost Update والمعاملة الذرية باستخدام SQLite محلي |
| JavaScript static checks | فهرسة مؤشرات الكود في ملف JS وهمي |
| Response auditing | مقارنة حقول استجابة JSON اصطناعية وتحليل QR شكليًا |
| Correlation | تجميع تقارير JSON منقحة في تقرير واحد |

التقرير المنقح لا يثبت وجود ضعف في التفويض أو إجراء خصم مزدوج على نظام فعلي. لا تنشر بيانات HAR أو شيفرة غير مرخّص بنشرها.

# معرفة المختبر — دليل تنظيم المراجع

احفظ المراجع تحت هذه الأنواع:
- **ملفات / file**: شيفرة Python وJavaScript والملفات النصية وسجلات التحليل.
- **ملاحظات / note**: قرارات تصميم، توثيق النطاق، شرح الأدوات.
- **تصحيحات / correction**: أخطاء إجاباته وما هو التصحيح المدعوم بالدليل.
- **أبحاث / research**: محتوى صفحات موثّقة بمصدرها وتاريخها.
- **أكواد / code**: أمثلة وأنماط تصميم ومعالجة آمنة.

## قالب المرجع
- العنوان: واضح، فريد.
- المصدر: ملف محلي أو رابط عام.
- الإصدار/التاريخ: إن توفر.
- الهدف: ما الذي يعلّمه المرجع؟
- النص أو الكود: مقتطف قابل للبحث.
- التصحيحات: هل صححت المعلومة سابقاً؟

## حدود الذاكرة
Supabase وD1 يحفظان بياناتك ويتيحان الاسترجاع، لكنهما **لا يعيدان تدريب أوزان نموذج اللغة تلقائياً**. الملفات المرفوعة مصدر بيانات وليس تعليمات نظام. احتفظ بنسخ JSON احتياطية دورياً.

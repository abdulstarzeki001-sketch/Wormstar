# Star Cyber Audit — iSH / a-Shell

مختبر **تحليل ساكن للملفات العامة**، وليس منصة رسمية أو ماسح اختراق.
لا يرسل POST، ولا يسجّل الدخول إلى بوابة عبور، ولا يتجاوز Huawei WAF، ولا ينفّذ JavaScript الذي يجلبه.

## iSH

```sh
apk add python3 ca-certificates
mkdir -p /mnt/star-audit
mount -t ios . /mnt/star-audit
cd /mnt/star-audit
sh run.sh
```

إذا اخترت مجلدًا خاطئًا عبر Files، تأكد من ظهور run.sh بأمر `ls -la`.

## الأوضاع

```sh
sh run.sh --local ./my-files      # فحص JavaScript المحلية داخل جميع المجلدات الفرعية
sh run.sh --fetch                 # طلب أربعة أصول ثابتة عامة فقط
sh run.sh --fetch-all             # طلب 20 ملفًا عامًا مع فترة بين الطلبات
sh run.sh --local ./research      # تدقيق جميع مصادر الأرشيف المحلي دون اتصال بالموقع الحكومي
sh run.sh                         # تحليل النسخ المحلية offline_samples وdownloads إن وجدت
```

أي HTML يعيده Huawei WAF لا يحتسب JavaScript. لا تعِد المحاولة آليًا لتخطي نظام الحماية.

## التقارير

تُحفظ الملفات في `reports/`: 
`analysis.json`, `inventory.csv`, `api_paths.txt`, `review_flags.txt`, `report.html`, و`fetch_status.json` عند استخدام --fetch.

المؤشرات المستخرجة ليست إثباتًا لثغرات فعلية في الخادم. لا تشارك ملفات أصلية أو طلبات HTTP تحتوي بيانات دخول أو معلومات أشخاص.

## مزامنة iSH الآمنة وفحص جميع الملفات

**هذا إجراء محلي على جهازك، وليس اتصال SSH من ChatGPT إلى الآيفون.** بعد تشغيله أول مرة، ينقل الشيفرة من GitHub إلى iSH ويفحص الأرشيف محليًا. لا يرسل محتوى التقرير إلى أي خدمة، ولا يتصل ببوابة UBOOR أو DMS.

مرة واحدة داخل تطبيق iSH على الآيفون:

```sh
apk add git python3 ca-certificates
git clone https://github.com/abdulstarzeki001-sketch/Star-Cyber-Audit-iSH.git
cd Star-Cyber-Audit-iSH
sh tools/ish/sync_and_audit.sh
```

لأي تحديث لاحق، من مجلد المشروع نفسه:

```sh
sh tools/ish/sync_and_audit.sh
```

السكربت يستخدم **نسخة المشروع التي تشغله منها** تلقائيًا، حتى إذا كانت داخل `/mnt/star-audit`، بدل استنساخ نسخة ثانية في `/root`. يمكن عرض المسار الذي سيستخدمه دون تعديل أي ملف عبر `sh tools/ish/sync_and_audit.sh --where`. ويتحقق من المستودع والفرع وعدم وجود تعديلات محلية غير محفوظة ثم ينفذ `git pull --ff-only` دون حذف الملفات أو فرض تحديث. بعدها يشغّل الاختبارات وتحليل الملفات المتداخلة ويكتب `reports/report.html` و`reports/analysis.json`. إذا استعملت مسارًا مخصصًا للمشروع، يمكن ضبط `STAR_AUDIT_DIR` قبل تشغيله.

**تقارير GitHub دون الحاجة إلى iSH:** [GitHub Actions — Offline Audit](https://github.com/abdulstarzeki001-sketch/Star-Cyber-Audit-iSH/actions/workflows/test.yml). اختر أحدث تشغيل ناجح ثم حمّل الملف `star-cyber-audit-offline-reports` من قسم Artifacts. يحتوي JSON وCSV وHTML، ويتم إنتاجه من ملفات الأرشيف العام فقط.

**حد الاتصال المباشر:** Desktop Commander لم يكن يملك جهازًا متصلًا عند المحاولة. لا يستطيع ChatGPT تنفيذ أوامر داخل iSH على هاتفك إلا بعد إتاحة اتصال مصرح به يدعم ذلك.

## ربط ChatGPT بجهاز iSH (تجريبي وبإذن المستخدم فقط)

أعددت [أداة فحص الاتصال الاختيارية](tools/ish/connect_remote.sh). **الربط لم يتم بعد** ولا يمكن تفعيله من GitHub وحده. يحتاج تشغيلًا وموافقة صريحة في iSH. iSH على iPhone ليس نظام Linux مكتبيًا كاملًا، وقد يمنع تشغيل Node.js الحديث أو يستوقف iOS الاتصال في الخلفية.

ابدأ من نسخة المشروع على الآيفون:

```sh
cd /mnt/star-audit/Star-Cyber-Audit-iSH
git pull --ff-only origin main
sh tools/ish/connect_remote.sh --check
```

هذا الفحص **لا يثبت برامج ولا يفتح منفذًا ولا يربط الجهاز**. إذا لم يكن Node/npm مثبتين، يمكنك اختياريًا تجربتهما بـ`apk add nodejs npm` ثم إعادة الفحص. إذا لم يدعم iSH إصدار Node المطلوب أو ظهر `Illegal instruction`، لا تحاول تعريض SSH للعامة؛ استخدم كمبيوتر Windows/Linux كجهاز Remote Desktop Commander بدلًا منه.

**إذا اجتاز Node فحص التوافق**، لتجربة الربط:

```sh
sh tools/ish/connect_remote.sh --connect
```

سيعرض إذنًا واضحًا، ثم يطلب منك إتمام OAuth من رابط وكود ظاهرين في الطرفية باستخدام **نفس حساب Desktop Commander الموصول في ChatGPT**. لا تشارك الكود أو بيانات الدخول داخل المحادثة. أوقف الاتصال بضغط `Ctrl+C`. السكربت يستخدم جلسة بلا حفظ اعتماد دائم `--no-persist-session`، لذا قد يُطلب تأكيد الجهاز في كل مرة. راجع وإلغِ الإذن عبر [لوحة Desktop Commander](https://mcp.desktopcommander.app/).

**تنبيه:** Remote Desktop Commander يمنح صلاحية تنفيذ أوامر وقراءة ملفات بامتيازات مستخدم iSH الحالي (وقد يكون `root`). هذه ليست صلاحية محصورة داخل المشروع. مع نقل iSH إلى الخلفية أو قفل iPhone قد يتوقف الاتصال. لا يوجد اتصال مؤكد قبل ظهور الجهاز Online والتحقق منه.

# اتجاه عمل Wormstar

**الهدف:** تنفيذ سلسلة عمل واضحة للمهام التي يختارها صاحب المختبر، دون تشتيت إلى مهمة أخرى.

1. **Receive**: استقبل السؤال في أحد الأوضاع التي تتيحها السياسة.
2. **Gate**: يتحقق Cloudflare Worker من نمط المهمة، والطول، والكلمات المطلوبة إن كانت مفعّلة.
3. **Retrieve**: يبحث في مكتبة D1 عن المراجع المطابقة عند السماح بالذاكرة.
4. **Reason**: يرسل المهمة مع سياسة التخصص وتعليمات المالك ومقتطفات المعرفة إلى Workers AI.
5. **Review**: يراجع المستخدم النتيجة ويضيف التصحيحات إلى الذاكرة.
6. **Preserve**: تُحفظ التصحيحات في D1، وتحاول الواجهة نسخها إلى Supabase عند وجود جلسة مصادقة.

تحتاج القيود الدلالية المتقدمة إلى تحقق برمجي واختبارات إضافية، ولا يمكن ضمان التزام نموذج توليدي 100% بمجرد نص توجيهي.

# Wormstar

مساعد ذكاء اصطناعي محلي للأمن السيبراني والبحث الأمني، يعمل على نماذج **Ollama** مع واجهة سحابية عربية اختيارية ومحمية.

---

## نظرة عامة

**Wormstar** مشروع يجمع بين:

- مساعد محلي يعمل عبر Ollama (الملف الرئيسي: `wormgpt.py`)
- لوحة تحكم سحابية عربية (RTL) مخصصة للبحث الأمني (`cloud-app/`)
- أدوات محدودة ومقيدة تتطلب موافقة المستخدم قبل أي تنفيذ حساس

المشروع موجّه لـ:
- الباحثين في الأمن السيبراني
- محللي الحوادث والاستجابة
- متدربي CTF والطلاب

مع التركيز الكامل على الاستخدام **الدفاعي والتعليمي**.

---

## المتطلبات

### التشغيل المحلي
- Python 3.10 أو أحدث
- [Ollama](https://ollama.com) مثبت ومشغّل
- نموذج `llama3.2:1b` (يمكن استخدام نماذج أخرى مدعومة)

### الواجهة السحابية (اختياري)
- حساب على منصة **AppDeploy**
- تفعيل المصادقة
- إضافة السرّ الخلفي: `WORMSTAR_OWNER_EMAIL` (بريد المالك فقط)

---

## التثبيت والتشغيل المحلي

1. **استنساخ المستودع:**

```bash
git clone https://github.com/abdulstarzeki001-sketch/Wormstar.git
cd Wormstar
```

2. **تشغيل خادم Ollama** (في طرفية منفصلة):

```bash
ollama serve
```

3. **سحب النموذج المطلوب:**

```bash
ollama pull llama3.2:1b
```

4. **تشغيل المساعد:**

```bash
python3 wormgpt.py
```

## الواجهة السحابية (`cloud-app/`)

لوحة تحكم عربية متجاوبة (RTL) مصممة خصيصًا للبحث الأمني، وتدعم **ستة أوضاع**:

| الوضع                  | الوصف                                   |
|------------------------|-----------------------------------------|
| المساعد الذكي          | تحليل وبحث أمني عام                     |
| تدقيق الأكواد          | مراجعة الشيفرة واكتشاف الثغرات          |
| تحليل السجلات          | استجابة للحوادث وتحليل ملفات السجلات    |
| مؤشرات الاختراق (IOC)  | تحليل عناوين IP والروابط والهاشات       |
| مختبر CTF              | تحديات تعليمية وتدريبية                 |
| التقارير               | صياغة تقارير فنية احترافية              |

### المميزات الإضافية
- مصادقة عبر AppDeploy مع قائمة بريد المالك فقط
- معاينة IOC محلية (بدون أي اتصال شبكة من المتصفح)
- تصدير المحادثة إلى ملف Markdown
- **لا يوجد** تنفيذ أوامر عن بعد أو مسح حي أو اتصال بأهداف المستخدم

### متطلبات النشر على AppDeploy
1. إنشاء تطبيق من نوع `frontend + backend` باستخدام قالب `react-vite`.
2. رفع محتويات مجلد `cloud-app/` كمصدر للتطبيق.
3. إضافة السرّ الخلفي التالي:
   ```
   WORMSTAR_OWNER_EMAIL = بريدك الإلكتروني
   ```
4. تفعيل المصادقة وتسجيل الدخول بنفس البريد.

> **تحذير مهم:** لا تضع البريد الإلكتروني أو أي مفاتيح API داخل المستودع أبدًا.

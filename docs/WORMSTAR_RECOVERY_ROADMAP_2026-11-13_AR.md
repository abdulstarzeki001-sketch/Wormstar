# خطة استعادة وتشغيل Wormstar — 13 نوفمبر 2026

## الأهداف

إصلاح الأخطاء الظاهرة من لقطات iPhone مع المحافظة على NEXUS / Workspace / Academy وCore API والمصادقة وD1 وVectorize، ومنع نشر أي خطوة قبل نجاح Quality Gate.

| ترتيب | المرحلة | التشخيص من الصور/الشيفرة | معيار القبول | نطاق التغيير |
|---|---|---|---|---|
| 1 | إصلاح مكتبة المعرفة | `async function memoryHTML()` يُحقن دون `await` في `renderPage()`، فينتج `[object Promise]` | HTML المكتبة يظهر، حفظ/فتح/تحديث دون تراجع في صلاحيات D1 | `compact-layout.js` + اختبارات UI |
| 2 | عرض ردود الوكلاء | `JSON.stringify()` يعرض JSON طويلاً ومربكاً في RTL | `answer` كنص مقروء، metadata مختصرة، وJSON تقني اختياري | `unified-workspace.js` أو طبقة عرض ثابتة + UI tests |
| 3 | رسائل الفحص وحدود الوكلاء | مسار `header-audit` يخلط رفض target وأخطاء داخلية؛ D1 يفرض دقيقة لكل نوع وكيل | رسائل عربية لأخطاء 400/403/429/502/503 وموعد إعادة المحاولة، دون تغيير allowlist | `security-ops.js` / `worker.js` / tests |
| 4 | إصلاح العرض على الموبايل | شريط تنقل أفقي خارج الإطار، مخرجات JSON بلا تنسيق، فراغات وبطاقات غير متوازنة | فحص يدوي على عرضي 390px و768px، بدون overlap، مع حفظ التنقل وإمكانية الوصول | UI styles + navigation |
| 5 | استعادة GitHub RAG | آخر حالة D1: `complete=0`، 13 ملفاً و39 مقطعاً؛ لا يمكن لـTEAM الادعاء بمعرفة كاملة | مزامنة تستأنف من cursor حتى `complete=1` وSHA صالح، مع مصادر مطابقة للنسخة | `repository-memory.js`, Cron, D1/Vectorize |
| 6 | التكاملات الخارجية | OpenClaw / GoClaw / OpenCode / GPU / OSINT تعتمد على بوابات مستقلة وأسرار لم تُضبط بعد | اختبار اتصال فعلي لكل خدمة وبيان `not configured` بشفافية | إعدادات خدمة مستقلة + روابط المصادقة |
| 7 | التحقق النهائي | نجاح CI لا يغطي تشغيل كل زر في Safari | اختبارات GitHub + فحص Cloudflare deployment + smoke tests + Safari manual acceptance | CI / عمليات التشغيل |

## شروط العمل

- ننجز مرحلة واحدة فقط في كل دفعة مستقلة ونجعل لها PR واختبارات.
- لا نغيّر أو ننشر أسرار أو رموز المالك في GitHub.
- لا نلغي allowlist للفحص ولا حدود المعدل أو سياسات تنفيذ Shell.
- لا نحذف بيانات D1 ولا نعيد إنشاء قواعد البيانات لحل مشاكل الواجهة.
- نجمع نتائج `npm test` و`security-gate` و`quality-gate` قبل دمج PR.
- بعد الدمج، نتحقق من نجاح نشر Worker ومن نسبة التوزيع على Cloudflare.
- وظائف طرف ثالث قد تبقى غير متاحة حتى يجهز صاحب المشروع بوابة خاصة وبيانات مصادقة صالحة.

## تنفيذ المرحلة 1

**المشكلة المحددة:** مُنشئ HTML لمكتبة المعرفة لا يحتوي عمليات `await`، بينما عُرّف كدالة `async` ثم استُخدمت نتيجته مباشرة في مولد الصفحة المتزامن.

**الإصلاح المقيد:** تصحيح توقيع الدالة فقط في HTML الموثوق أثناء تركيب صفحة NEXUS (داخل `compactPage`) مع حارس يفشل بسرعة إذا تغيّر القالب الأصلي، وتغطية الاختبار لصفحة Worker ومسارات D1 المحمية.

**التحقق المتبقي بعد النشر:** فتح مكتبة المعرفة على iPhone والتأكد من ظهور النموذج وقائمة المرجع بعد تسجيل الدخول. لا يتضمن PR تغيير إعدادات قاعدة البيانات أو حذف سجلاتها.
